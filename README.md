# โปรแกรมทำเอกสารโครงการก่อสร้าง (ConsDocx)

เว็บแอปสร้างเอกสารราชการสำหรับโครงการก่อสร้าง กรอกข้อมูลครั้งเดียวแล้วสั่งออก .docx ได้ทุกฉบับ

**เปิดใช้งาน: https://dstaokung.github.io/ConsDocx/** — v1.0

## เอกสารที่รองรับ

| หมายเลข | ชื่อเอกสาร |
|---|---|
| 1 | ขออนุมัติโครงการก่อสร้าง |
| 2 | คำสั่งแต่งตั้งคณะกรรมการ |
| 3 | รายงานการประชุมแบบรูปรายการ |
| 4 | บันทึกรายงานแบบรูปรายการ |
| 5 | นำส่งเอกสารการขออนุมัติ |
| 6 | บันทึกขออนุมัติแต่งตั้งคณะกรรมการกำหนดราคากลาง |
| 7 | คำสั่งแต่งตั้งคณะกรรมการกำหนดราคากลาง |
| 8–11 | ชุดเอกสารราคากลาง (รายงานการประชุม, รายงานราคากลาง, นำส่ง, แบบ บก.) — เลือกชุดตามประเภทงาน × วิธีจัดซื้อจัดจ้าง |

## วิธีใช้

1. เปิดโปรแกรมที่ลิงก์ด้านบน
2. กรอกข้อมูลทั้งหมดในหน้าเดียว (ชื่อโครงการ, งบประมาณ, คณะกรรมการ, เลขที่/วันที่หนังสือ ฯลฯ)
   ข้อมูลถูกจำไว้ในเครื่องอัตโนมัติ ปิดแล้วเปิดใหม่ก็ยังอยู่
3. กด **สร้างไฟล์** ข้างเอกสารที่ต้องการ — ได้ไฟล์ .docx ทันที
4. กด **สร้างไฟล์ทั้งหมด (.zip)** เพื่อออกเอกสารทั้งชุดพร้อมกัน
5. งานราคากลางอยู่ที่แท็บ **"ราคากลาง (เอกสาร 8–11)"** — เลือกประเภทงาน กรอกราคากลางที่คำนวณได้
   แล้วสร้างได้เหมือนกัน (วิธีจัดซื้อจัดจ้างโปรแกรมคิดจากงบประมาณให้ ต่ำกว่า 5 แสน = เฉพาะเจาะจง,
   5 แสนถึงต่ำกว่า 1 ล้าน = e-bidding, 1 ล้านขึ้นไป = e-GP)

ช่องวันที่พิมพ์ย่อได้ (`1/2/2569`, `1 ก.พ. 69`) โปรแกรมแปลงเป็น "1 กุมภาพันธ์ 2569" ให้เอง
ช่องที่เว้นว่างไว้ โปรแกรมจะเติมข้อความตั้งต้น/ช่องว่างให้แทน แล้วทำเป็น**ตัวอักษรสีแดง**ในไฟล์ที่ได้
เพื่อให้เห็นชัดว่าตรงไหนต้องกลับมาแก้

## โครงสร้าง repo

| ตำแหน่ง | หน้าที่ |
|---|---|
| `index.html` | หน้า redirect ไปยัง `forms/main.html` |
| `forms/main.html` | ทั้งโปรแกรมอยู่ในไฟล์นี้ไฟล์เดียว — ฟอร์มกรอกข้อมูล + สร้าง .docx ทั้ง 7 ฉบับ |
| `forms/main-template-data.js` | เทมเพลต .docx ทั้ง 7 ฉบับในรูป base64 (1 บรรทัด = 1 เอกสาร) — สร้างด้วย `tools/gen-template-data.py` |
| `templates/ขออนุมัติโครงการ/` | ไฟล์ .docx ต้นแบบของเอกสาร 1–7 |
| `templates/ราคากลาง/<ประเภทงาน>/<วิธี>/` | เทมเพลตเอกสาร 8–11 จำนวน 9 ชุด (อาคาร/ทาง/ชลประทาน × เฉพาะเจาะจง/ebidding/egp) |
| `forms/template-data/` | base64 ของชุดราคากลาง ชุดละไฟล์ + `rc-index.js` (สารบัญ) — โหลดเฉพาะชุดที่ใช้ตอนกดสร้าง |
| `templates/PLACEHOLDERS.md` | คู่มือ placeholder ทั้งหมด + ขั้นตอนเพิ่มเอกสารใหม่ |
| `tools/gen-template-data.py` | regenerate base64 ของเทมเพลต — **ต้องรันทุกครั้งที่แก้ไฟล์ .docx** |
| `tools/test-build-docs.js` | `node tools/test-build-docs.js` — ทดสอบสร้างเอกสารทุกฉบับ เช็คว่าไม่มี placeholder ค้าง |
| `shared/` | ไลบรารีกลาง (JSZip, docx.lib, เดือน/ปีไทย, ธีม, ตราครุฑ ฯลฯ) |

> เดิมเคยมีหน้าฟอร์มแยกรายเอกสารที่ `forms/<N>. <ชื่อเอกสาร>/` — ยุบมารวมที่ `forms/main.html`
> หมดแล้ว (ดูของเดิมได้ใน git history) ข้อมูลเก่าที่ผู้ใช้เคยกรอกไว้จะถูกย้ายขึ้นมาให้อัตโนมัติครั้งแรกที่เปิด
